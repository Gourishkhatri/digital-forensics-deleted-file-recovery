Case Name: Deleted File Recovery Investigation
Examiner: Gourish Khatri
Environment: Controlled Training Laboratory
Forensic Tool: Autopsy 4.23.1
Forensic Image: DFR-001-E002.E01


1. INVESTIGATION OBJECTIVE
--------------------------
The objective of this controlled laboratory investigation was to
identify and recover deleted files from a synthetic forensic image
using Autopsy.


2. EVIDENCE SOURCE
------------------
Data Source: DFR-001-E002.E01
Image Type: E01 forensic image
Environment: Synthetic training evidence
Timezone: Asia/Calcutta (GMT+5:30)


3. ANALYSIS PROCESS
-------------------
The forensic image was loaded into Autopsy 4.23.1.

The following ingest modules were used:

- File Type Identification
- Extension Mismatch Detector
- Embedded File Extractor
- Picture Analyzer
- Keyword Search
- Interesting Files Identifier
- PhotoRec Carver
- Data Source Integrity

Ingest processing completed successfully.


4. DELETED FILE ANALYSIS
------------------------
Autopsy identified deleted/unallocated file entries within the
forensic image.

Relevant recovered evidence was identified and reviewed using
the Autopsy Result Viewer and Content Viewer.

7. EVIDENCE HANDLING
--------------------
The recovered files were extracted from the forensic image and
stored separately in the Recovered-Files directory.

The recovered evidence items were tagged in Autopsy using the
"Recovered Evidence" tag.

Three recovered evidence items were included in the generated
HTML forensic report.

----------

9. REPORTING
------------
An HTML forensic report was generated using Autopsy.

10. CONCLUSION
--------------
The controlled laboratory investigation successfully demonstrated
the identification and recovery of deleted synthetic files from a
forensic image using Autopsy.

Three relevant deleted evidence items were recovered, reviewed,
hashed, tagged, and included in the final HTML forensic report.

This investigation was performed entirely using synthetic training
evidence in a controlled laboratory environment.
